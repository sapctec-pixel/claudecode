# BEAUTIQUE SALON - Wireframe

## Layout Philosophy

Editorial, fashion-magazine approach. Generous whitespace. Asymmetric grids. Typography as the primary design element. Monochrome palette with warm accent (#C4A07C) used sparingly for CTAs and highlights.

---

## 01. Header (Fixed)

```
+------------------------------------------------------------------+
|  BEAUTIQUE                    Services  Pricing  About  Contact  |
|  S A L O N                                          [Book Now]  |
|                                               [AR/EN]  [D/L]    |
+------------------------------------------------------------------+
```

- Fixed top, transparent on hero, solid on scroll
- Logo: BEAUTIQUE in tracked-out uppercase, SALON beneath in smaller caps
- Language toggle (AR/EN) and dark/light mode toggle
- Mobile: hamburger menu, slide-in panel from right (RTL) or left (LTR)

## Responsive Breakpoints

| Breakpoint | Width | Layout Changes |
|------------|-------|----------------|
| Mobile | < 640px | Single column, hamburger nav, stacked sections |
| Tablet | 640-1024px | Two-column grids, condensed spacing |
| Desktop | > 1024px | Full layout, side-by-side sections, larger typography |

## Animation Notes

- All sections: fade-up on scroll enter (Intersection Observer)
- Hero: text slides up with staggered delay
- Service cards: staggered reveal left-to-right (RTL: right-to-left)
- Testimonials: crossfade between quotes
- Booking CTA: subtle scale pulse on the accent background
- Header: blur backdrop on scroll
- No animation on `prefers-reduced-motion: reduce`
