## Responsive Behavior

### Mobile (< 768px)
- Header: hamburger or simplified nav
- Hero: reduced padding, smaller type
- Services: single column card stack, category tabs scroll horizontally
- Offers: single column stack
- About: image above text, full width
- Team: two-column grid or single column
- Before/After: stacked vertically
- Testimonials: single column
- Contact: stacked, map below info

### Tablet (768px - 1024px)
- Two-column grids where applicable
- Services: two cards per row
- Team: three cards per row
- Before/After: side by side

### Desktop (> 1024px)
- Full layout as wireframed above
- Three-column grids for services and team
- Side-by-side about section
