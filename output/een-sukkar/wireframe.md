# Een Sukkar - Landing Page Wireframe

## Layout Overview
Single-page scrolling layout with sticky header navigation. Warm, open feel with generous spacing and rounded elements. RTL/LTR responsive.

---

## Header (Sticky)
```
+-----------------------------------------------------------------------+
|  [Logo/Brand]          [Story] [Dishes] [Order] [Contact]   [AR/EN] [Theme] |
+-----------------------------------------------------------------------+
```
- Frosted glass background on scroll
- Compact, functional
- Language toggle and theme toggle as icon buttons
- Mobile: hamburger menu with slide-in drawer

## Responsive Breakpoints
- **Mobile** (< 640px): Single column, stacked layout, hamburger nav
- **Tablet** (640px - 1024px): 2-column grids, condensed hero
- **Desktop** (> 1024px): Full layout as wireframed

## Interaction Notes
- Smooth scroll between sections on nav click
- Fade-up animation on section enter (intersection observer)
- Hover lift on cards (translateY + shadow)
- Theme toggle: smooth CSS variable transition
- Language toggle: instant content swap, direction flip
